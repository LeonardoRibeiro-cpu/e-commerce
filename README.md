# E-Commerce API - Backend

Este é o repositório do backend de um sistema de E-commerce, desenvolvido em Java com Spring Boot. O projeto faz parte das atividades do curso de Tecnólogo do Instituto Federal do Triângulo Mineiro (IFTM) - Campus Uberlândia Centro.

## 🚀 Tecnologias Utilizadas

* **Java**
* **Spring Boot**
* **Maven** (Wrapper incluído)
* **RESTful API**
* **DTO**
* **Mapper**
* *JPA**

## 📂 Estrutura do Projeto

O projeto segue a arquitetura focada no desenvolvimento de APIs REST, organizando a lógica de negócios e as rotas de acesso. Alguns dos principais controladores implementados incluem:

* `CategoriaController`: Responsável pelo gerenciamento de categorias dos produtos.
* `ClienteController`: Responsável pelo gerenciamento das informações dos clientes.

## ⚙️ Como Executar

1. Clone o repositório para a sua máquina local.
2. Navegue até a pasta raiz do projeto (`e-commerce`).
3. Dê permissão de execução ao wrapper do Maven (se necessário):
   ```bash
   chmod +x mvnw
   ```
4. Execute o comando Maven para iniciar a aplicação:
   ```bash
   ./mvnw spring-boot:run
   ```
*(No Windows, você pode utilizar o executável `mvnw.cmd`)*
